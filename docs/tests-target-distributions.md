# Целевые распределения профилей

Статус: утверждено основателем 03.08.2026. Коридоры — закон для робота
(машинная форма `tools/tests-audit/corridors.json`, вердикты
`check-corridors.mjs`: симуляция вне коридора = FAIL). Перекалибровка
порогов этапа 2 выполнена — все 19 тестов в коридорах; финальные пороги и
обоснования — в `$note` внутри `profileSelection` каждого
`tools/tests-import/fixes/<id>.json`. Три открытых вопроса ниже по тексту
(№8 типология границ, №11 среда выгорания, №12 формулировка q7 детокса)
остаются открытыми — в этап 2 не входили.

Принципы («тёплая» калибровка, решение основателя 03.08):

- «Хороший» исход (здоровый / надёжный / мастерский) — достижим для **15–25%**
  последовательных респондентов, а не 1–3%, как сейчас.
- Fallback / «смешанный» — **≤25–30%** (у типологий ≤20–25%): большинство должно
  уходить с именным результатом.
- Тяжёлый уровень — **3–7%** (верхний экстрим 1–5%): достаточно редкий, чтобы
  быть весомым, достаточно достижимый, чтобы не быть декорацией.
- Середина уровневых тестов — **≤35%**: «у тебя средне» — самый слабый результат
  и для шеринга, и для конверсии.
- Каждый написанный профиль достижим и получает ≥1–2% (мёртвых нет).

Оговорки, чтобы цифры читались честно:

1. «Сейчас» и «цель» — доли на **персонной симуляции** (4000 коррелированных
   «людей», tools/tests-audit/audit2.mjs), не на реальной популяции. Реальные
   люди дадут другие цифры; после запуска Э9 распределения сверяются с прод
   (уровень L5) и коридоры пересматриваются. Симуляция — это линейка, которой
   мы меряем геометрию правил, а не пророчество.
2. Точные пороги в «рычагах» — стартовые точки; финальные значения подбираются
   симуляцией до попадания во все коридоры теста одновременно.
3. Для тестов, где этап 2 меняет данные (полюса sixteen_types, реверсы
   romantic, перекодировка social_battery), распределение «сейчас» устареет
   само — коридоры задаются для состояния ПОСЛЕ этих фиксов.

## Как утверждаем

Правь цифры прямо в таблицах или ответь списком «тест: профиль → коридор».
Два открытых вопроса внутри (№8 типология границ — v2?; №11 вынос среды из
среднего выгорания; №12 переформулировка q7 детокса) — жду решения по ним
отдельно. После утверждения: коридоры уходят в спеки тестов (front matter),
робот L2 начинает их проверять, этап 2 калибрует пороги до попадания.
