   обе функции их импортируют. Паритет со старой логикой доказан байт-в-байт:

2. **Фиксы фидов (8d0f2c4).** Разбор (95 кр):
   - `quote_candidate` направлен ПО ФАКТОРУ: на 157 реверсивных вопросах маркер
     зеркалится. Было: «Мне сложно высказывать несогласие» + «Всегда» → `max`
     ассертивности; стало `min`. В промпт добавлена полстроки семантики
     (max = крайний ответ, поднимающий фактор). Безфакторные вопросы (полюса
     sixteen) не зеркалятся — их веса читают сырой балл.
   - Биполярные тесты не шлют `factor_percentages` (структурные нули
     {EI:0, SN:0…} модель читала как «крайняя интроверсия») и не шлют
     `scale_scores_0_100` (полюсные абсолюты по модулю — нарушение семантики
     Э3); pair_balances остаются — это и есть читаемая форма.
   - `scaleDigest`: при ≤12 шкал уходит единый упорядоченный список `all`
     вместо среза top-8/bottom-4 (у love_languages «lowest» был пуст, шкала
     с 20 могла сидеть под ярлыком «highest»).
   Портрет (145 кр):
   - **Отбор «сильные + противоречивые»** вместо сортировки |combined−50| со
     срезом 18: `cross_test_scales.contested` — шкалы с межтестовым разбросом
     ≥30, топ-20 по разбросу (у каждой записи поле `spread` и by_test);
     `cross_test_scales.strongest` — топ-20 по удалённости от 50 из остальных.
   - **Полюсные пары схлопнуты в оси**: `type_axes` — 4 пары балансами
     («extraversion 61 / introversion 39») общий + по каждому тесту, где оба
     полюса измерены ≥2 вопросами. Полюса больше никогда не ходят в фид
     поодиночке.
   - **Порог вклада**: тест говорит о шкале только с ≥2 вопросов
     (одновопросные вклады скачут 0↔100 и рождали ложные «противоречия»;
     статически это −192 вклада из 749, сквозных шкал 125 → ~102).
   - **`profile_summary`** — первая фраза описания профиля (модель не знала,
     что значит «Хранитель границ»); сырой `profile_id` из фида убран.
   - **Кэш портрета сверяет `engine_version` при чтении**: после следующей
     перекалибровки стейл-портрет тихо перегенерируется — бесплатно, потому
     что spend-key (user + set_hash) не меняется; стейл-строка не отдаёт свой
     второй язык в merge. Локальная копия ENGINE_VERSION убрана — импорт из
     движка.
   - Промпт портрета описывает contested/strongest/type_axes (короткая правка
     SYSTEM_BASE, стиль и рамки не тронуты).

## До/после: сколько противоречий доезжает до модели

Симуляция коррелированных персон (та же модель, что в аудите §5): 60 персон
полного каталога, по 40 — случайных пятёрок и троек. «Противоречие» = шкала
с межтестовым разбросом ≥30 в соответствующей вселенной (v2 — после фильтра
шума, т.е. это более честные противоречия, чем в v1).

| Метрика | Полный каталог (19) | 5 тестов | 3 теста (гейт) |
|---|---|---|---|
| Топ-10 громких коллизий в фиде | 8% → **100%** | 25% → **100%** | 53% → **93%** |
| Все противоречия в фиде | 13% → 40% | 27% → **97%** | 49% → **100%** |
| Противоречий на персону | 108 → 82 | 36 → 22 | 16 → 9 |
| Размер фида | ~12.8K → ~25.2K зн. (~6.3K ток.) | ~6.7K → ~12.5K (~3.1K) | ~5.5K → ~7.3K (~1.8K) |

Прежний фид был анти-коллизионным по построению (шкала 90-в-одном/10-в-другом
даёт combined ≈50 и вылетает первой) — теперь самые громкие противоречия
гарантированно в фиде, а на реальных ранних составах (3–5 тестов) доезжает
практически всё. Прирост входных токенов у полного каталога ~+3K — копейки
на фоне 145-кредитного SKU.

Пример живого фида v2: `tools/tests-audit/out/portrait-feed-example.json`
(после `npm run tests:portrait-sim`).

## Развилки на решение (константы в `_shared/portrait-input.ts`)

1. **Лимит противоречий** `CONTESTED_CAP` (сейчас 20). У полного каталога за
   бортом остаётся ~60 более тихих (guaranteed-покрытие по симуляции):

   | cap | гарантированно в фиде | цена в токенах |
   |---|---|---|
   | **20 (рекомендую)** | 25% (+спилловер через strongest → 40%) | +0 |
   | 30 | 37% | ~+620 |
   | 40 | 49% | ~+1200 |
   | без лимита | 100% | ~+3100 |

   Рекомендация 20: топ-10 громких всегда внутри, а в 230 слов throughlines
   больше 3–4 коллизий всё равно не помещается — дальше идёт разбавление
   внимания модели, не глубина. Поднять — правка одной константы.
2. **`STRONG_CAP` 20, `SPREAD_THRESHOLD` 30, `MIN_ITEMS_PER_CONTRIBUTION` 2** —
   те же соображения, менять по одной строке.
3. **Digest у биполярных убран целиком** — аудит требовал только не слать
   нулевые факторы; я убрал и полюсные абсолюты (то же нарушение «полюс не
   читается по модулю», pair_balances несут ту же информацию честно). Вернуть —
   одна строка.
4. **`profile_id` из tests_taken портрета убран** (сырой id рядом с запретом
   печатать snake_case — соблазн без пользы). Вернуть — одна строка.
