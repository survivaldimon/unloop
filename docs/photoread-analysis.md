# Photoread: дедуктивный портрет (v3)

Спека структуры анализа фото-воронки после переработки 28–29.07.2026 по
фидбеку основателя. Код: `supabase/functions/photoread-analyze` (тизер),
`supabase/functions/photoread-report` (полный отчёт), фронт `src/photo/*`.

## Что было не так в v2 (фидбек 28.07)

1. Много описания кадра, мало выводов о характере.
2. Нет привычных ярлыков (темперамент, интро/экстраверсия).
3. Дисклеймеры в каждом разделе — при том, что рамка показана до оплаты.
4. Водяные разделы: «История за 10 секунд», «Поза и присутствие»,
   «Обстановка и кадр», «Разбор сигналов» по баллам, «Радар восприятия».
5. Нет сочетаемости черт (что «дружит», что конфликтует, с примерами).
6. Флаги вялые.
7. Перспектива сломана: при чужом фото (сайт знакомств) отчёт давал советы
   «какое фото поставить главным» — не тому человеку.

## Принципы v3

- **Метод — дедукция**: каждая мысль идёт цепочкой «улика → привычка →
  черта». Плейбок улик зашит в системный промпт (осанка/пространство, тип
  улыбки, взгляд, ухоженность, одежда, тату по стилю и месту, аксессуары,
  фон, сам снимок как поступок). Один сигнал — слабый, сходимость сигналов —
  уверенный вывод. Научная опора: суждения по фото при нулевом знакомстве
  (thin slicing), «поведенческий осадок» среды, признаки Duchenne-улыбки.
- **Смелость без диагнозов**: ноль оговорок в тексте («возможно», «нельзя
  судить по фото» — запрещены промптом); два жёстких запрета — клинические
  диагнозы и обвинения в преступлениях. Народные ярлыки — можно и нужно.
- **Ярлыки, которые узнают**: темперамент (холерик/сангвиник/флегматик/
  меланхолик и гибриды), интроверт/экстраверт/амбиверт, Большая пятёрка,
  2–3 народных архетипа («душа компании», «контрол-фрик»…).
- **Перспектива по subject** (передаётся в аттестации промпта):
  - `me` — читатель = человек на фото; обращение на «вы», советы по подаче
    уместны, photos_verdict разрешён.
  - `us` — читатель на фото с близким; химия черт читается по видимой
    динамике пары; photos_verdict разрешён.
  - `other` — читатель смотрит на чужой профиль; о человеке на фото — в
    третьем лице, НИКАКИХ советов по его профилю, photos_verdict = null;
    вместо «главной правки» — «что проверить при встрече».
- **Контекст по use_case**: dating затачивает химию/вердикт под пару,
  professional — под работу, social — под образ для аудитории.

## Структура отчёта (REPORT_SCHEMA)

| Поле | Секция UI | Содержание |
|---|---|---|
| first_impression | I. Первое впечатление | типаж с ходу, без описания сцены |
| deductions[5–7] | II. Дедукция | {clue, inference} — улика → смелый вывод |
| profile | III. Типаж | temperament, social_energy, archetypes[2–3] — всё с «почему» |
| big_five | IV. Большая пятёрка | 5 шкал {score 0–100, evidence}; рендер — биполярные бары от центра |
| chemistry | V. Химия черт | inner (сочетания внутри характера), clashes[2–3] и matches[1–2] — {trait, with_trait, scenario-сцена} |
| green_flags / red_flags | VI. Флаги | массивы {label, evidence, meaning}, смело |
| the_tell | VII. The Tell | фирменная деталь (бренд-секция, не тронута) |
| verdict | VIII. Вердикт для <контекста> | итог под use_case |
| next_move | IX (бокс) | me/us: главная правка; other: 2–3 проверки гипотез вживую |
| photos_verdict | X. Вердикт по набору | только me/us и >1 фото, иначе null |

Тизер (analyze): два вывода-дедукции + locked_hint про самую острую черту.

## Совместимость со старыми сессиями

Отчёт генерится один раз и кэшируется навсегда, фото удаляются — старые
сессии навсегда v2. Рендер определяет форму по полю `deductions`
(`isLegacyReport` в `src/photo/api.ts`); v2 рисует замороженный
`PhotoReportLegacy.tsx` (его копирайт и радар живут внутри компонента,
`copy.ts` их больше не знает). Диплинки из старых писем работают.

## Платёжный переход (починка лагов, та же итерация)

- `PayState` получил `"opening"`: с клика по CTA до появления оверлея кнопка
  занята («Открываем оплату…») — раньше 1–4 с выглядели как зависание, а
  двойной клик открывал два чекаута.
- `preloadCheckout()` при маунте тизера греет lazy-чанк Polar embed.
- Guard от повторного клика в `startUnlock`/`unlockWithBalance`/`buyTopUp`.
- Багфикс RU-оглавления на пейволле: строка вердикта подставляется по
  `id: "verdict"`, а не по сравнению с английским заголовком.

## Деплой v3 (чек-лист)

1. `supabase functions deploy photoread-analyze` — новый тизер-промпт.
2. `supabase functions deploy photoread-report` — новая схема+промпт
   (max_tokens 5000; модель та же claude-sonnet-5).
3. Фронт: build + Pages deploy (легаси-рендер уже в бандле, порядок
   деплоя фронт/функции не важен — обе формы поддерживаются).
4. Смоук: RU+EN тизер на своём фото (subject=me) и на чужом (other/dating);
   проверить отсутствие советов по профилю при other и наличие
   photos_verdict при me+несколько фото.
